Skins

No skins yet.

Add one by dropping its folder in website/skins/:

website/skins/my skin/
   my skin.png            the skin
   preview.my skin.png    the preview picture

Then run python3 website/tools/bake-skins.py once and reload - that writes the folder list where this page reads it. To remove a skin, delete its folder and bake again.
